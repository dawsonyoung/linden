# Glossary

> **Status:** Stub.

Terms used across the specification. Define a term here the first time the spec depends on it meaning something precise.

**Device** — A machine on the user's network running Linden or connecting to it.

**Host** — The machine running the Linden server.

**Model backend** — The local process that performs inference. Ollama in the initial release.

**Session** — A single conversation thread.

**Streaming** — Delivery of a reply in fragments as it is generated, rather than in one response after completion.
